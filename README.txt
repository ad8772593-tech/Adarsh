MYSHOP - ONLINE STORE STARTER

FILES
- index.html  : Website structure and page content
- style.css   : Colours, layout, and responsive design
- script.js   : Product display, search, category filters, and demo cart

HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to view the website in a browser.
4. To publish it online, upload these files to a static website host.

CUSTOMIZE
- Change the shop name and text in index.html.
- Edit the products array near the top of script.js to add your own products.
- Change colours and styles in style.css.

IMPORTANT
This is a front-end starter/demo. It does not include a real payment gateway,
customer accounts, order database, admin dashboard, or delivery integration.
Do not collect customer payment or personal details with this demo.
A real online store needs a secure backend and a trusted payment provider.
